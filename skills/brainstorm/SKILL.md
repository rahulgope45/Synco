---
name: brainstorm
description: Explore Synco feature or architecture options when there is a real design choice or the user requests brainstorming.
---

Read ai-context/INDEX.md and the relevant feature only. Frame the problem and success metric.
Compare two or three viable options using synchronization accuracy, native complexity, offline operation, and testability where relevant.
Recommend one and identify the smallest experiment that would change the recommendation.
Ask only for missing information that affects the decision. Routine reversible choices do not need approval.
Save accepted decisions in the feature context; mark unaccepted ideas as proposals. Brainstorming alone does not authorize implementation or expand MVP scope.
